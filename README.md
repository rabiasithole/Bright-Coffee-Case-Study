# ☕ Bright Coffee Shop — Sales Analysis

A data analytics case study for a fictional three-location coffee shop chain, focused on 
identifying revenue drivers, peak sales periods, and actionable growth recommendations 
for a newly appointed CEO.

**Role:** Junior Data Analyst | **Dataset:** 149,116 transactions | Jan–Jun 2023 | 3 store locations

---

## 🎯 Project Objectives

- Identify which products generate the most revenue
- Determine what time of day the store performs best
- Analyze sales trends across products and time intervals
- Deliver actionable recommendations to improve overall sales performance
